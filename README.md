Weather Website

About the Project

This is a simple and responsive weather website that provides weather information for different locations. The project is designed to demonstrate the use of web development and weather API concepts.

Features

- Search weather by city
- Display temperature
- Display weather conditions
- Show humidity and wind information
- Responsive design for mobile and desktop
- Simple and user-friendly interface

Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

Project Structure

weather-website/
├── index.html
├── style.css
├── script.js
└── images/

How to Run

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Search for a city to view its weather information.
